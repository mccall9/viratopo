# Information Architecture: ViraTopo

## Site Map

- Quadro `/`
- Ranking `/ranking`
- Estatísticas `/analytics`
- Regras `/termos`
- Privacidade `/privacidade`
- Painel `/painel`

## Navigation Model

Desktop usa Quadro, Regras e Estatísticas. No mobile a marca retorna ao Quadro; links secundários permanecem no rodapé para evitar uma barra comprimida.

## Content Hierarchy

1. Iniciar entrada pelo endereço do produto.
2. Entender lance e posição disponível.
3. Consultar ranking, regras e dados públicos.

## User Flow

Quadro → inserir URL → identificação → recibo PIX demonstrativo → aviso de confirmação.
